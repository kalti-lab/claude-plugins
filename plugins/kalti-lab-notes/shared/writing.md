# 낱말 — 볼트에 쓰는 모든 글에 걸린다

일지, 카드, 보고서, 소식, 그리고 사람에게 하는 말까지 전부 해당한다. 이 파일은 `kalti-journal` · `kalti-ontology` · `kalti-report` · `kalti-context`가 글을 쓰기 전에 읽는다.

## 규칙 하나

**한국 사람이 실제 대화에서 쓰는 낱말만 쓴다.** 글에서나 보이는 말, 번역투, 설명하려고 새로 만든 비유는 안 쓴다. 지적받고 고치는 게 아니라 **처음 쓸 때부터** 그렇게 쓴다.

## 실제로 걸린 것들

전부 이 볼트에서 실제로 나온 문장이다.

| 쓴 것 | 대신 |
|---|---|
| 가설이 **닫혔다** | 판가름 났다 · 결론이 났다 |
| 대체안이 바로 **섰다** | 대신할 방법이 바로 나왔다 |
| 차이가 **씻겨나간다** | 차이가 없어진다 · 사라진다 |
| **뒤집힌 것** (제목) | 예상이 빗나간 것 |
| 기억은 실행을 가로지르는 **평면이다** | 한 군데가 아니라 실행 전체에서 쓴다 |
| Honcho에 **뒤진다** | 못 미친다 |
| 훨씬 **둔한 자**가 된다 | 결과가 훨씬 들쭉날쭉해진다 |
| 실전 **방어선**이었다 | 실제로 사고를 막았다 |
| 최대 **부채** | 제일 많이 손봐야 할 것 |
| **일반칙** | 어디에나 통하는 규칙 |
| 사람이 **검출기**다 | 사람이 눈으로 봐야만 잡힌다 |
| 어딘가에 **절벽**이 생긴다 | 어딘가에서 뚝 끊긴다 |
| **층위**가 다르다 | 성격이 다르다 |
| 감사를 **공허 통과**한다 | 검사할 대상이 0개라 그냥 합격한다 |
| 품질은 **미증명**이다 | 품질은 아직 확인 못 했다 |
| **대체안** | 대신할 방법 |
| 투명도 **소실** | 투명도가 사라짐 |
| **기제** · **기전** | 어떻게 그렇게 되는지 |

**목록에서 뺀 것 셋** — `자루`는 빗자루(아이콘 이름)에 걸렸고, `뒤집힌 것`은 "상관 0.14로 뒤집힌 것을 잡아내"처럼 멀쩡한 쓰임이 있고, `공허 통과`는 dsforge가 만들어 쓰는 이름이자 카드 이름이라 `게이트`·`하네스`와 같은 부류다.

## 비유를 새로 만들지 않는다

층 · 자루 · 평면 · 방어선 · 검출기 · 절벽 같은 말은 설명이 아니라 장식이다. 읽는 사람이 그 비유를 풀어야 뜻에 닿는다면 그냥 뜻을 쓴다.

## 기술 용어는 뜻을 먼저, 이름은 괄호에

```
안 됨    kv 평탄화를 피하라
됨       키와 값을 한 줄로 눕히는 방식(kv 평탄화)은 쓰지 마라

안 됨    평가 하네스를 확장했다
됨       시험을 돌리는 장치(하네스)를 넓혔다
```

한 글 안에서 처음 나올 때 한 번만 풀어 주면 되고, 그다음부터는 이름만 써도 된다.

**프로젝트가 원래 쓰는 이름은 바꾸지 않는다.** dsforge의 `게이트`, 직렬화포맷의 `실측`, dsmonitor의 `하네스` 같은 것은 그 팀의 말이다. 처음 나올 때 풀어 주기만 한다.

## 개념은 사례부터

정의를 먼저 말하지 말고 실제로 있었던 일을 먼저 보여 준다.

```
안 됨    조용한 실패란 에러 없이 성공처럼 보이는 실패를 말한다.
됨       적재 훅이 꺼진 줄 알았는데 실제로는 거부당하고 있었다.
         에러가 안 나서 몇 주 뒤에야 알았다 — 이런 걸 조용한 실패라고 부른다.
```

## 파일 이름은 손대지 않는다

카드와 일지 이름은 위키링크가 찾아가는 주소다. 이미 있는 이름에 딱딱한 말이 들어 있어도 **바꾸지 않는다** — 링크가 다 깨진다.

- **새로 짓는 이름**은 이 규칙을 따른다.
- **글 안에서 옛 이름을 가리킬 때**는 별칭으로 가린다: `[[사고를-켜면-포맷차이가-씻겨나간다|생각을 시키면 포맷 차이가 없어진다]]`
- 표 안에서는 구분자를 `\|`로 적는다: `[[이름\|쉬운 말]]`

## 일지는 쓴 사람만 고친다

**자기가 쓴 일지는 낱말을 고쳐도 된다.** 남이 쓴 일지는 고치지 않는다 — 그 사람의 기록이고 고쳐 쓰지 않는 증거다.

카드(`ontology/`)는 함께 관리하는 지식이라 누구나 고쳐도 된다. 보고서(`reports/`)는 다시 만들면 된다.

**카드가 인용한 문장을 고칠 때는 카드도 같이 고친다.** 카드는 일지 문장을 따옴표째 옮겨 근거로 삼는다. 일지만 고치면 카드의 인용이 원문과 달라져 근거가 아니게 된다. 둘을 같은 커밋에서 함께 바꾼다.

## 기계가 잡아 주는 범위

`shared/lint.py`가 확실한 것 몇 개만 경고로 잡는다. **대부분은 기계가 못 잡는다** — 이 볼트에서 재 봤더니 넓게 잡으면 1,873건이 걸리는데 그중 82%가 `게이트`·`실측`·`하네스`·`전사`처럼 그 팀이 원래 쓰는 말이었다. 좁혀서 119건만 남겼다.

그러니 lint가 조용하다고 잘 쓴 게 아니다. 문장을 쓸 때마다 **"이 낱말을 말로 할 때도 쓰나"**를 스스로 본다.
